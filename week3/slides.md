## `enum`

- Represents a fixed set of constants

```java
public enum BookType {HARD_COVER, PAPERBACK, KINDLE};
public enum SUITS {SPADE, HEART, DIAMOND, CLUB};
```

---

## `enum`

- Improves readability
- Easier than declaring a bunch of constants
- Can be used in `switch` statements

---

## `switch`

- Sort of a shortcut for a lengthy `if`
- Originally `byte`, `short`, `char`, `int`, their wrappers, enums, and Strings
- Pattern matching in most recent versions of Java

```java
        String grade = "B";
        double gpa = 0;
        switch (grade) {
            case "A":
                gpa = 4.0;
                break;
            case "B":
                gpa = 3.0;
                break
            case "C":
                gpa = 2.0;
                break;
            default:
                gpa = 0;
        }
```

---

## Enhanced `switch`

- An *expression* rather than a statement.


```java
return switch (rank) { 
	case Constants.TWO, Constants.ACE -> 20;
	case Constants.THREE -> (suit.equals(Constants.HEART) || suit.equals(Constants.DIAMOND)) ? 0 : 5;
	case Constants.FOUR, Constants.FIVE, Constants.SIX, Constants.SEVEN, Constants.EIGHT -> 5;
	case Constants.NINE, Constants.TEN, Constants.JACK, Constants.QUEEN, Constants.KING -> 10;
	case Constants.JOKER -> 50;
	default -> -1;
};

```

## Library Management System

- Maintain a collection of items that can be loaned out
  * can be books or magazines
  * could also be media, tools...
- Check out individual publications
- View all available publications

---

## Design

- Need basic functionality
  * whether it is checked out
- Books and magazines have a title
- Books have an author name (magazines don't have one author)
- Magazines have a volume
- LPs have an artist

---

## Interfaces

- Specify behavior (methods) but not implementation
- Could have a `LibraryItem` *interface*
  * check out
  * return

---

## Abstract classes

- Cannot be *instantiated*
- Provide some behavior but not all
- Could have a `Publication` abstract class
  * title

---

## Concrete classes

- Can *implement* multiple interfaces
- Can *extend* one other class
